Academic Projects

XYZ Manufacturing Database Design (Fall Term 2025)

As part of a team of 3, The team designed a relational database for a manufacturing company's customer order and product application. Starting from a set of business requirements, I helped identify entities, business rules, and candidate keys, then built conceptual and physical entity-relationship diagrams, normalizing the design and resolving many-to-many relationships between customers, orders, products, and parts. The team wrote the DDL scripts to create the tables, keys, and constraints, populated the database with test data, and authored a series of SQL queries covering joins, aggregates, GROUP BY/HAVING, and subqueries, along with dynamic and materialized views.

GitHub Repo Link: https://github.com/prou0212/XYZ-Manufacturing-Company

Record Collection Database Design (Winter Term 2026)

As part of a team of 3, I helped design and build a database application for managing a vinyl record collection, tracking artists, albums, songs, genres, and record labels. The system uses Microsoft SQL Server as the backend, connected through SSMS, with Microsoft Access as the frontend, providing forms for adding, editing, and searching records, along with built-in reports for albums by artist, albums by genre, and songs by album. I worked on modeling the database relationships, including many-to-many links between artists, albums, songs, and producers, and helped build out the Access forms, search functionality, and backup/restore process for the SQL Server database.

GitHub Repo Link: https://github.com/prou0212/Record-Collection
